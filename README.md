# Lamur Shell — iOS-style home screen components

This repository contains example QML components implementing an iOS-like home screen (grid of app icons, dock, wallpaper) generated by GitHub Copilot.

Files added in feature/ios-shell:
- qml/Main.qml
- qml/components/AppGrid.qml
- qml/components/Dock.qml
- qml/resources/icons/*.svg (placeholder icons)
- qml/resources/images/wallpaper.svg (placeholder wallpaper)

Notes:
- These components use Qt Quick and Qt Graphical Effects (GaussianBlur). Ensure your project includes Qt Graphical Effects in CMake or qmake.
- Replace the placeholder SVG icons and wallpaper with real assets as needed.
